KELEI BIOR — PERSONAL PORTFOLIO

FILES
- index.html: page structure and content
- style.css: navy, forest green and black visual design; responsive layouts
- script.js: mobile navigation, active section tracking and automatic footer year

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a browser, or open the folder in Visual Studio Code.
3. For local development, use the VS Code Live Server extension.

PERSONALISE BEFORE PUBLISHING
- Replace your.email@example.com in index.html with your real email address.
- Replace the two sample project cards with real project names, screenshots and links.
- Add your GitHub profile URL and any other social links you want to share.
- Review the wording and update it as your experience grows.

The Google Fonts import requires an internet connection; the site still works with fallback fonts.
